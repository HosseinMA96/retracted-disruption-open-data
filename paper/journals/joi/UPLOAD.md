# JOI upload instructions

JOI uses **single-anonymized review**, confirmed by the author from the official guide on 26 November 2026:
https://www.sciencedirect.com/journal/journal-of-informetrics/publish/guide-for-authors .
Use the **identified** manuscript: keep the author's name, affiliation and public GitHub link.
The build script now generates only this submission version.

| Upload item | File(s), relative to this folder |
|---|---|
| Editable LaTeX manuscript source | `joi_latex_source.zip` (identified); eight flat members: `main.tex`, bibliography/style/class files and all three figures |
| Figures, if requested as separate upload items | `submission/fig1_forest.pdf`, `submission/fig2_event.pdf`, `submission/fig3_population_flow.pdf` |
| Required separate editable highlights | `highlights.docx` (Word); `highlights.txt` is the matching plain-text source |
| Competing-interests statement | `competing_interests.docx`, **after replacing the locally generated draft with the official Elsevier declarations-tool output** |
| Cover letter | `cover_letter.pdf` or its editable `cover_letter.tex`, as the system requests |
| Supplementary material | `supplement.pdf` (two pages; source `supplement.tex` with `../../content/supplement.tex`) |
| Separate title page, only if requested | `title_page.pdf` or `title_page.tex` |

Do **not** use `submission_anon/` or `joi_latex_source_anon.zip`: these are legacy artifacts and omit the GitHub link.
Do not upload `main.pdf` as a substitute for editable manuscript source. The local PDF in `submission/` is a preview,
not a member of the LaTeX ZIP. If the system asks for individual source files instead of a ZIP, upload the eight
ZIP members directly from `submission/`, including the editable `main.tex` and all three figures.
If using the public repository rather than a local build, first extract the ZIP into `submission/`;
that generated folder is not separately published.

**The Elsevier declarations tool should always be completed when uploading**, even when there are no competing
interests: https://declarations.elsevier.com/ .
It has not been completed here. The official page was reachable on 27 November 2026 (UTC), but its interactive
browser workflow could not be completed with the available CLI/web-fetch tools.
The local DOCX contains the prepared wording but is
not a tool-generated declaration; retain the official generated `.doc`/`.docx` without overwriting it with another
local build (the build script regenerates the draft DOCX).

**Before approving submission:** inspect the PDF generated by Editorial Manager using pdfLaTeX/BibTeX.
Local builds use Tectonic, so they do not prove the submission-system build is correct. Check the author block,
GitHub link, equations, tables, references, figures, keywords and absence of missing citations or glyphs.
The source is ASCII elsarticle and does not require XeLaTeX.

are required: 3--5 bullets, each at most 85 characters including spaces, in a separate editable file.
Upload `highlights.docx`; its text is checked against `highlights.txt`.
